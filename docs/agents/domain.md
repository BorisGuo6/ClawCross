# Domain Docs

This repo uses a single-context domain layout:

- `CONTEXT.md`: Clawcross domain language and invariants.
- `docs/repo-index.md`: task-oriented codebase map. Read this before touching code.
- `docs/adr/`: architectural decisions, when a choice should not be re-litigated.

Engineering skills should read `CONTEXT.md` and the relevant section of `docs/repo-index.md` before proposing architecture changes, diagnosing behavior, writing tests, or creating implementation tasks.
